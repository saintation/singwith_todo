# Singwith To-Do List 📝

**Singwith To-Do List**는 1인 사용자를 위해 설계된 극도로 가볍고 안전한 서버리스(Serverless) 프라이빗 할 일 관리 도구입니다. 

복잡한 데이터베이스나 백엔드 서버 없이, 오직 브라우저와 **GitHub Issues API**만을 사용하여 사용자의 Private 저장소에 데이터를 직접 읽고 씁니다. 모든 기록이 깃허브의 '이슈(Issue)' 형태로 관리되어 완벽한 버전 관리와 타임라인 추적이 가능하며, 향후 AI 에이전트가 사용자의 일정을 분석하고 회고할 수 있는 **'AI-Ready Data'** 생태계를 구축합니다.

## ✨ 핵심 기능 (Key Features)

* **GitHub Issues 기반 서버리스 DB:** 별도의 데이터 파일 없이, 태스크는 하나의 '이슈(Issue)', 메모는 '본문(Body)', 목표일은 '라벨(Label)'로 완벽하게 1:1 매칭되어 깃허브 서버에 안전하게 보관됩니다. 다중 기기 접속 시에도 충돌(Conflict)이 발생하지 않습니다.
* **낙관적 UI (Optimistic UI) 및 제로 딜레이:** 사용자가 상태를 변경하면 화면(로컬 캐시)에 즉시 반영되며 API 통신은 백그라운드에서 조용히 처리됩니다. 네트워크 지연 없이 네이티브 앱 수준의 쾌적한 렌더링 속도를 제공합니다.
* **AI-Ready 자동 감사 로그 (Automated Audit Log):** 사용자가 '상세 메모'를 수정하면 이전 기록이 유실되지 않고 해당 이슈의 **댓글(Comment)**로 자동 기록됩니다. 시스템이 생성 시점, 완료 시점, 내용 변경 이력을 타임라인 형태로 영구 보존합니다.
* **스마트 딥 서치 및 무한 스크롤:** 아카이브(Archive) 화면에서는 GitHub Search API를 활용하여 20건 단위의 무한 스크롤(페이징) 조회를 지원하며, 숨겨진 메모 내용까지 단숨에 찾아내는 실시간 키워드 검색을 제공합니다.
* **반응형 미니멀리즘 디자인:** 모바일(한 손 조작)에 최적화된 레이아웃을 기본으로 하되, PC 웹 브라우저에서는 최대 850px까지 넓어지는 반응형 웹(Responsive Web)을 지원합니다. 타이핑 양에 따라 무한으로 늘어나는 플렉시블 텍스트에어리어를 제공합니다.

## 🚀 시작하기 (Getting Started)

이 앱은 별도의 회원가입이 없습니다. 본인의 GitHub 계정과 권한 토큰(PAT)을 마스터 키로 사용합니다.

### 1. 접속 링크 및 파일 활용
🔗 **웹앱 바로 실행하기:** [https://saintation.github.io/singwith_todo](https://saintation.github.io/singwith_todo)

💡 **직접 호스팅하기:** 이 저장소에 있는 `index.html` 파일 단 하나만 복사하거나 다운로드하여 본인의 환경(로컬 PC, 다른 호스팅 등)에서 실행하셔도 모든 기능이 독립적으로 완벽하게 작동합니다.

### 2. 사전 준비 사항 (Data Repository Setup)
앱에 로그인하기 전, 데이터를 저장할 나만의 '비밀 금고'가 필요합니다.
1. GitHub에서 새로운 **Private** 리포지토리를 생성합니다. (예: `my-todo-data`)
   *(주의: 깃허브 리포지토리의 기본 기능인 'Issues'가 활성화되어 있어야 합니다. 보통 기본으로 켜져 있습니다.)*
2. GitHub `Settings` > `Developer settings` > `Personal access tokens (classic)` 에서 새로운 토큰을 발급받습니다. 
   * **필수 권한(Scope):** `repo` 전체 체크

### 3. 로그인 및 연동
접속 링크로 앱에 들어가면 로그인 화면이 나타납니다.
* **리포지토리:** 앞서 생성한 데이터 저장소 경로를 `[깃허브ID]/[저장소이름]` 형식으로 입력합니다. (예: `saintation/my-todo-data`)
* **GitHub PAT:** 발급받은 액세스 토큰을 입력합니다.
* '접속하기'를 누르면 즉시 동기화가 시작됩니다.
* Tip! 비밀번호 저장/관리 기능을 활용하여 매번 PAT를 입력하지 않도롣 하는 것이 사용에 편리합니다. (단, 보안 주의)

## 📖 사용 방법 (Usage Guide)

### Active Tasks (현재 할 일)
* **직관적인 인라인 제어:** 상단 입력창에 할 일을 적고 `Add` 버튼을 누릅니다. 생성된 태스크 하단의 뱃지를 클릭하면 즉시 목표일자를 달력으로 지정하거나 변경/삭제할 수 있습니다.
* **자동 펼침 메모:** 클릭하여 태스크를 펼치면 상세 메모를 작성할 수 있습니다. 메모가 1글자라도 작성된 태스크는 앱을 다시 켜도 항상 펼쳐진 상태를 유지하여 잊지 않도록 돕습니다.
* **완료 및 보관:** 좌측의 체크박스를 누르면 취소선이 그어지며 즉시 화면에서 사라져 'Archive'로 넘어갑니다.

### Archives (보관함)
* 우측 상단의 `Archive →` 버튼을 눌러 접근합니다. 
* **완료일 자동 정렬:** 최근에 완료한 과업 순(내림차순)으로 자동 정렬됩니다. 스크롤을 끝까지 내리면 과거의 기록을 20건씩 이어서 불러옵니다.
* **딥 서치 & 필터링:** 돋보기 아이콘 창에 키워드를 입력하고 `Enter`를 누르거나 돋보기 버튼을 누르면 과거의 메모 기록까지 완벽하게 찾아냅니다. 날짜 필터를 통해 특정 기간에 끝낸 일들을 모아볼 수도 있습니다.
* **데이터 보호:** 아카이브된 항목은 실수로 내용이 지워지는 것을 막기 위해 '읽기 전용'으로 전환되며, 삭제 버튼이 숨겨집니다. 다시 'Active'로 돌리고 싶다면 체크박스를 해제하면 됩니다.

## ⚠️ 주의 및 한계 사항 (Limitations)
* **GitHub API 호출 제한 (Rate Limit):** **일반 API는 시간당 5,000회**로 넉넉하지만, 아카이브의 **검색(Search) 기능은 분당 30회**의 엄격한 제한이 있습니다. 검색 버튼을 단기간에 수십 번 연타하지 마십시오.
* **토큰 보안:** 발급받은 PAT는 브라우저의 로컬 메모리에만 일시적으로 유지됩니다. 공용 PC에서 사용 시 반드시 브라우저 탭을 완전히 닫아주십시오.
