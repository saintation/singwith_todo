# Singwith To-Do List 📝

**Singwith To-Do List**는 1인 사용자를 위해 설계된 극도로 가볍고 안전한 서버리스(Serverless) 프라이빗 할 일 관리 도구입니다. 

복잡한 데이터베이스나 백엔드 서버 없이, 오직 브라우저와 **GitHub API**만을 사용하여 사용자의 Private 저장소에 데이터를 직접 읽고 씁니다. 특히, 모든 기록을 순수 JSON 파일 형태로 관리하여 향후 다양한 AI 에이전트(LLM)가 사용자의 일정을 분석하고 회고할 수 있는 **'AI-Ready Data'** 생태계를 구축하는 것을 목표로 설계되었습니다.

## ✨ 핵심 기능 (Key Features)

* **서버리스 아키텍처 (Serverless & Data Sovereignty):** 모든 할 일 데이터는 사용자의 GitHub Private 저장소에 `data.json` 형태로 안전하게 저장됩니다.
* **AI 친화적 데이터 설계 (AI-Ready Data):** 데이터가 폐쇄적인 앱에 갇히지 않고 표준 JSON 규격으로 누적됩니다. 이는 추후 AI를 활용한 개인 일정 요약, 패턴 분석, 맞춤형 피드백 생성 등 확장적 활용을 완벽하게 지원합니다. [데이터예시](https://github.com/saintation/singwith_todo/blob/main/data.json)
* **마찰 없는 입력 (Frictionless Entry):** 상시 노출된 입력창을 통해 즉각적인 태스크 추가가 가능하며, 필요한 경우에만 목표 일자를 지정할 수 있습니다.
* **아카이브 시스템 (Archive & History):** 완료된 작업은 'Archive' 뷰로 자동 이동되며, 조회 기간 필터를 통해 과거의 성과를 쉽게 추적할 수 있습니다. 과거 데이터의 무결성을 위해 아카이브된 메모는 '읽기 전용(Read-only)'으로 전환됩니다.
* **완벽한 다크 모드 (Native Dark Mode):** 눈의 피로를 덜어주는 깊은 회색 톤(#0F0F0F, #1A1A1A)의 테마와 브라우저 네이티브 다크 모드 달력 UI를 제공합니다.
* **스마트 딥 서치 및 자동 펼침 (Smart Deep Search & Auto-expand):** 아카이브(Archive) 화면에서 키워드 검색 시, 태스크의 제목뿐만 아니라 숨겨진 '메모' 내용까지 탐색합니다. 일치하는 키워드는 붉은색으로 시각적 강조(Highlight) 처리가 되며, 메모 내부에 검색어가 포함된 경우 해당 상세 영역이 자동으로 펼쳐져 추가적인 클릭 없이 즉시 내용을 확인할 수 있습니다.
* **탐색과 실행의 분리 (Context Isolation):** 현재 집중해야 할 과업(Active)과 과거의 기록을 탐색하는 영역(Archive)을 시각적, 기능적으로 완벽히 분리하여, 검색창은 아카이브 화면에서만 나타나도록 설계되었습니다.

## 🚀 시작하기 (Getting Started)

이 앱은 별도의 회원가입이 없습니다. 본인의 GitHub 계정과 권한 토큰(PAT)을 마스터 키로 사용합니다.

### 1. 접속 링크 및 파일 활용
🔗 **웹앱 바로 실행하기:** [https://saintation.github.io/singwith_todo/](https://saintation.github.io/singwith_todo/)

💡 **직접 호스팅하기:** 제가 배포해 둔 위 링크에 접속해서 바로 사용하셔도 되지만, 이 저장소에 있는 **[index.html](https://github.com/saintation/singwith_todo/blob/main/index.html) 파일 단 하나만 복사하거나 다운로드**하여 본인의 GitHub Pages, 로컬 브라우저, 또는 다른 호스팅 환경에 직접 올려서 사용하셔도 무방합니다. (HTML 파일 하나로 모든 기능이 독립적으로 작동합니다.)

### 2. 사전 준비 사항 (Data Repository Setup)
앱에 로그인하기 전, 데이터를 저장할 나만의 '비밀 금고'가 필요합니다.
1. GitHub에서 새로운 **Private** 리포지토리를 생성합니다. (예: `my-todo-data`)
2. 리포지토리 최상단 경로에 `data.json` 파일을 만들고 내용에 `[]` 를 입력한 후 저장합니다.
3. GitHub `Settings` > `Developer settings` > `Personal access tokens (classic)` 에서 새로운 토큰을 발급받습니다. 
   * **필수 권한(Scope):** `repo` 전체 체크

### 3. 로그인 및 연동
접속 링크(또는 실행한 index.html)로 앱에 들어가면 로그인 화면이 나타납니다.
* **리포지토리:** 앞서 생성한 데이터 저장소 경로를 `[깃허브ID]/[저장소이름]` 형식으로 입력합니다. (예: `singwith/my-todo-data`)
* **GitHub PAT:** 발급받은 액세스 토큰을 입력합니다.
* '접속하기'를 누르면 즉시 동기화가 시작됩니다.
* Tip! 비밀번호 관리 기능을 활용해서 매번 PAT를 입력하지 않도롣 하는 것이 편리합니다. (보안 주의)

## 📖 사용 방법 (Usage Guide)

### Active Tasks (현재 할 일)
* **추가:** 상단 입력창에 할 일을 적고 `Enter`를 누르거나 `Add` 버튼을 클릭합니다. 선택적으로 목표일을 지정할 수 있습니다.
* **세부 메모 및 수정:** 리스트 항목을 클릭하면 하단으로 상세 영역이 펼쳐집니다. 이곳에서 추가 메모를 작성하거나, 지정했던 목표일을 수정 및 삭제할 수 있습니다.
* **완료 처리:** 좌측의 체크박스를 누르면 취소선이 그어지며, 다음 동기화 시 자동으로 Archive 화면으로 넘어갑니다.
* **영구 삭제:** 세부 영역 우측 하단의 '삭제' 버튼을 누르면 확인창을 거친 후 데이터베이스에서 완전히 파기됩니다.

### Archives (보관함)
* 우측 상단의 `Archive ➔` 버튼을 눌러 접근합니다.
* **기간 필터링:** 상단의 날짜 필터를 통해 특정 기간(완료일 기준)에 끝낸 일들을 모아볼 수 있습니다.
* **데이터 보호:** 아카이브된 항목의 메모와 날짜는 수정할 수 없습니다. 실수로 완료 처리한 경우, 체크박스를 다시 해제하면 Active 뷰로 원상복구됩니다.
* **키워드 검색:** 상단의 검색창에 단어를 입력하면 조건에 맞는 태스크만 즉시 필터링됩니다. 메모 내용에 검색어가 포함되어 있다면 해당 메모가 자동으로 펼쳐져 렌더링됩니다.

## ⚠️ 주의 및 한계 사항 (Limitations)
* **네트워크 지연:** 저장 시 GitHub API와 통신하므로, 네트워크 상태에 따라 1~2초의 `SYNCING...` 딜레이가 발생할 수 있습니다. 동기화가 끝날 때까지 창을 닫지 마세요.
* **토큰 보안:** 발급받은 PAT는 브라우저의 메모리에서 세션을 유지하는 용도로만 사용됩니다. 공용 PC에서 사용 시 브라우저 종료 후 캐시를 비우는 것을 권장합니다.
